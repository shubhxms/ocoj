# metro-hacks

Hackathon workspace (on-board the Gujarat Metro). The main project is **OCOJ** — a
multi-modal (metro + BRTS + AMTS bus) journey router for Ahmedabad with fare-Pareto
optimization. See [`OCOJ/README.md`](OCOJ/README.md).

Raw public data pack lives in `metro-hacks-data/` (not committed; ~350 MB) with a
`START_HERE.md` describing provenance and trust levels per source.
